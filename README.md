# 🌸 4-U ASCII Art Flower

A single-file, self-contained ASCII art animation of a blooming flower — built in HTML/CSS/JavaScript and rendered entirely in the browser. No build tools, dependencies, or server required.

## Features

- 🌺 An animated ASCII-rendered flower with a glowing pink/magenta blossom and green stem
- ✨ A drifting starfield background
- 📊 Live on-screen stats overlay — bloom percentage, stem sway angle, and total character count
- 🪶 Runs entirely standalone from a single HTML file

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/r0Othaha/4-U-ASCII-ART-FLOWER.git
   ```
2. Open `4-U.html` in your browser (double-click it, or drag it into a browser tab).

That's it — no installation, no dependencies.

## Preview

The flower blooms and sways in place while the stats overlay in the corner updates in real time, showing the current bloom stage, sway angle, and letter count making up the art.
